# 1.5.0 正式版 — 2026-11-19

本版本将已发布的1.4.19-beta完整晋升到main正式版，包含该beta的运行功能与累计修复。正式版版本号、发布清单和安装包统一为1.5.0；默认更新通道为stable。

## 本次纳入正式版

- 桌面岗位文档配置、私有项目元数据、全文评估与OCR命中标注、可选AI总评。
- 推荐列表自动滚动、推广卡跳过、双列候选识别，以及按实际平均速度调整单人查看和连续招呼休息时间。
- 悬浮窗持续置顶且不抢焦点；岗位不符或零筛选时提醒并等待30秒，回复“继续”可跳过等待。
- 日期目录外层保留独立最终Excel，图片、OCR和同岗同日唯一记录快照放入“运行记录”；取消CSV/.data自动导出。
- 本机岗位修改、历史运行、账本、资料及可用运行环境的保留与安装备份。

## 安装与升级

发布附件为boss-recruiting-1.5.0.zip、同名.zip.sha256与.zip.sig。安装前必须完成Ed25519验签与文件清单校验。

已有安装在首页第4项“更新项目”选择“更新主版本（main）”，或使用已验证的scripts/skill_update.py update --channel stable。处于beta通道的用户须明确选择主版本通道切换，beta不会自动切换到正式版。活动或暂停招聘运行须先结束。

首次安装仍须从官方GitHub HTTPS仓库取得可信scripts/bootstrap.ps1。共享项目继续加密分发；私有候选资料、账本、凭据及自建项目不进入公开源码。

历史实景验证范围及待验收项继续参考V1.4.10-VALIDATION.md和后续验证记录。本次版本晋升不代表重新执行真实候选发送。
