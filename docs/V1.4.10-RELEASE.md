# 1.4.10 发布说明

本版本提供逐份补足查看时长、CSV与Excel自动刷新展示、本地OCR关键词标色、同事记录不可读提示、多列遍历、筛选提醒及页面缩放，并修复截图进程和停止确认的问题。历史运行继续使用原快照。

## 配置与升级

岗位来源为Windows实际桌面下“自动招呼/02 招呼配置”，每家企业一个文件夹、每个岗位一份MD及配套隐藏元数据。记录写入“自动招呼/01 招呼记录”。若升级前只使用程序内profiles，先备份并整理到本地目录；缺少有效本地岗位时菜单不会回退旧profiles或擅自选择岗位。HR模板见HR-JOB-TEMPLATE.md。不要将空模板作为有效岗位。

现有HR普工文档的词库保留本地修改，不会被包内默认值覆盖。需要移除独立减分词“主管”时，先结束所有招聘运行，用独立Python运行scripts/migrate_worker1410.py --apply --db <实际ledger.sqlite3路径>；工具会核验空闲并逐份备份，只修改元数据明确标为普工的文档。不改其他岗位、包含“主管”的更长词或历史快照。

新日表首次生成时建立CSV查询和Excel展示表，此后默认每分钟和打开时刷新，不是每写一条立即刷新。旧日表按报表归属进行验证和备份切换；安装本身不会立即重建全部历史表。初始化失败时保留数据和待配置状态，不覆盖旧表。

配置30秒时处理12秒补等18秒，已达30秒不额外等；0关闭。明确近期同事记录仍跳过，读取不清时须逐人在当前聊天提示“跳过了同事沟通记录判断”后才允许继续其他评估。

OCR保留原图、文字与JSON；命中词绿、减分词红，定位不可靠的词只旁注。误判复诊仅提供建议标记，不自动删除词或改分。

## 验证与已知限制

已完成隔离回归、本地OCR、Excel保持打开的三批自动刷新、本机签名安装及真实页面缩放测试。真实左右双列布局和明确含同事沟通记录的简历仍待实景验收，详见V1.4.10-VALIDATION.md。

安装包提供ZIP、SHA-256与Ed25519签名，更新前须验签。岗位资料仅在加密包中；候选人记录、账本、本机密钥和运行环境不随发布上传。
