# 本地岗位启动入口

每次进入 quick_start.py 或 project_registry.py 的菜单，重新读取 Windows 实际桌面下的“自动招呼/02 招呼配置”。支持桌面重定向；BOSS_DESKTOP_DIR 供隔离测试使用。企业以该目录下的企业文件夹为范围，岗位只取企业文件夹内可读取、可启动的 MD。根目录填写模板不作为岗位，隐藏、备份及链接目录不自动纳入。缺少或无法解析的配置给出列表提示，不回退程序内的旧 profiles。

唯一匹配的企业与岗位生成 ready_to_start 计划，保留请求中的招呼及查看人数，沿用既有浏览器登录、直接启动和规则快照流程。企业简称支持前缀匹配；企业与岗位均匹配时取交集，不能把属于其他企业的岗位选中。多岗位或同名岗位要求选择，未匹配返回六项主菜单及本地企业列表，不猜测上次岗位。

主菜单保留：1 继续上次项目，2 查看所有本地企业，3 创建新的项目，4 更新项目，5 测试配置环境，6 退出打招呼。查看所有包含空企业文件夹并显示可用岗位数量；菜单1表示打开主菜单，单独回复1才表示继续。创建指向配置目录中的“岗位填写模板.md”，更新、环境测试和退出沿用原处理流程。

继续前重新检查上次岗位是否仍在当前本地列表中。运行中、暂停及需要登录的有效历史运行保留原 run_id 续接，不改写其规则快照；已结束项目按当前MD准备新运行。不存在或无效的岗位返回菜单。保存的待启动计划在实际创建运行前再次查询本地目录，删除、归档、锁定或格式错误不能从旧计划绕过；实际创建运行仍从当前MD编译JSON。

本功能随1.4.10安装包提供，沿用本地配置目录和当前聊天的受控招聘流程。
