# v1.5.1 本机更新

- 列表“减分词库”更名“否决词库”，正向命中后二筛，任一否决词命中直接跳过，不开简历。电子简历的减分词库保留。
- 岗位文档新增达标复盘开关、人物画像和偏好地点；优缺点摘要开关规范为“AI优缺点判断”，兼容“AI总评”。按实际岗位开关决定复盘，分数不被AI改写。
- 只匹配牛人分析器明确提供的偏好地点，缺失、读取失败与不匹配分别处理，AI不能覆盖地点拒绝。地点初始清单及人物画像由本机已确认资料整理，不上传明文。
- 非推荐牛人页先在准确绑定的内置浏览器中进入推荐页，再做布局和候选读取。
- 每15秒由独立助手探测准确绑定的聊天，连续三次确认意外空闲后尝试恢复一次。UIA仅监测，不修改输入框；没有可验证的原桌面聊天投递通道时暂停提醒。可用通道45秒未确认恢复则暂停，不重复续发。
- 原动态等待±5秒保留。旧运行快照、旧复盘请求、候选记录、用户项目及运行环境保留。
- 本机岗位迁移与技能安装共用维护锁、备份和恢复记录，失败共同回滚。构建可显式选择stable或beta，默认行为不变。

本次交付本机安装与签名包，不包含GitHub发布。真实网页导航、分析器字段和聊天探测的可用性以当前桌面UIA证据为准；自动化测试不代替真实招呼验证，也不发送测试招呼。
