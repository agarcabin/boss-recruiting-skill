# V1.5.10 — 2026-11-24

基线：1.5.8-beta

## 变更

- 运行器启动时写入并应用 Windows `ForegroundLockTimeout=200000`，阻止后台 UIA 点击抢焦点；原值记录在账本，需要人工恢复时使用 `foreground_lock.restore()`。
- 从本地 1.5.3 选择性合并求职意愿筛选。
- 合并牛人分析器 OCR 断字和换行解析，兼容 `VIP专享`/`IP专享` 噪声、`求职意/愿强` 断字、地点换行和行政区换行。
- 新增牛人分析器“沟通Boss超过 X% 的同类牛人”解析和岗位门槛。
- 新增岗位配置：`求职意愿筛选`、`无牛人分析器处理`、`沟通Boss门槛`、`沟通Boss未知处理`。

## 规则

- 求职意愿只接受明确允许的 `较强`/`强`。
- `沟通Boss门槛` 默认 `0%`，`0%` 为关闭；填 1–100 时百分位必须严格高于门槛才打招呼；`沟通Boss未知处理` 默认 `符合`，读不到时继续。
- 整块牛人分析器缺失时按 `无牛人分析器处理` 执行。
- 规则分和 AI 复盘边界不被改写。
