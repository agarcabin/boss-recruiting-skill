# 1.5.3 正式版 — 2026-11-20

本版本将1.5.1本地更新及1.5.2-beta、1.5.3-beta的累计改动晋升到main正式版，正式版版本号、发布清单和安装包统一为1.5.3；默认更新通道为stable。

## 本次纳入正式版

- 发布包内置无第三方依赖的MCP控制服务，使用技能自带runtime；首次升级后打开岗位菜单或启动任务时，仅在缺少配置时注册`[mcp_servers.recruiting]`，已有配置、旧原型、注释停用和内联配置保持原样。
- MCP新增一次启动、收尾、候选人列表及带cursor/events的长轮询工具；注册前备份`config.toml`，无效配置不写入，不新增Python依赖。
- 列表否决词二筛：任一否决词命中即跳过且不打开简历；岗位文档新增独立达标/扣分复盘开关、人物画像和偏好地点。
- 偏好地点仅按牛人分析器明确提供的信息判断：缺失或读取失败默认通过，明确不匹配才跳过，行政区无法唯一解析时待复核。
- 推荐牛人入口、独立聊天中断监测及GPT状态监测修复；推荐列表改为约一屏的大步滚动，推广卡和双列候选识别保持。
- 动态等待、持续置顶悬浮窗、30秒提醒等待、独立最终Excel、本机项目/历史运行/账本/运行环境保留与安装备份继续有效。

## 安装与升级

发布附件为boss-recruiting-1.5.3.zip、同名.zip.sha256与.zip.sig。安装前必须完成Ed25519验签与文件清单校验。

已有安装在首页第4项“更新项目”选择“更新主版本（main）”，或使用已验证的scripts/skill_update.py update --channel stable。处于beta通道的用户须明确选择主版本通道切换，beta不会自动切换到正式版。活动或暂停招聘运行须先结束。

首次安装仍须从官方GitHub HTTPS仓库取得可信scripts/bootstrap.ps1。共享项目继续加密分发；私有候选资料、账本、凭据及自建项目不进入公开源码。MCP配置切换后需重启Codex加载工具。

历史实景验证范围及待验收项继续参考V1.4.10-VALIDATION.md和后续验证记录。本次版本晋升不代表重新执行真实候选发送。
