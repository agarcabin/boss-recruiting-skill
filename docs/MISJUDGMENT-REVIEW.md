# 电子简历误判复诊

岗位文档在“电子简历 → 减分词库”后新增“误判复诊”，填写开或关。旧岗位文档未填写时默认开启；不改变已有词库匹配和评分。

完整简历有正向命中、原本满足正向条件，但因负向词被淘汰时，运行器返回 `needs_misjudgment_review`。旧普工计分路径仅在负向扣分使分数从合格降至不合格时触发。列表初筛、不完整正文、没有正向命中或原本就不满足正向条件时不触发。

助手读取请求中的完整正文，逐项分析负向词是否表示真实的不合适经历或身份。例如“主管过喷漆”可能是负责工序，“曾任生产主管、管理30人”则是真实的主管经历；应结合全文而非只看词附近一句话。请求包含正文与规则摘要生成的标识，旧正文的答复不能用于新正文。

答复必须回传请求标识，并逐词提供判断、全文原句与理由。明确不必要的扣分才在原岗位电子简历负向词后添加 `（🔴建议删除）`。必要或不确定的词保留。注释不参与词库匹配，重复复诊不叠加标记。写入前核对岗位未被修改、先备份，原子替换；用户修改了配置时只报告建议写入失败，不覆盖修改。

复诊是建议机制，不自动删除词、撤销扣分或授权发送。原评分、其他岗位条件及同事检查继续生效。复诊结果保存在运行审计中，原规则快照不修改；新增的纯建议标记不改变运行配置校验值。

本功能随1.4.10安装包提供。安装后的助手必须使用配套 SKILL.md，才能自动处理新增交接状态。
