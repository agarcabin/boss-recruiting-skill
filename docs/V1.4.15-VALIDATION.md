# 1.4.15-beta 发布验证

日期：2026-11-17（Asia/Shanghai）。发布目标分支：`codex/wecom-cloud-knowledge`。

本次将当前开发源码中的修复与混合执行改造统一打包为 1.4.15-beta。列表、点击、滚动、同事记录、招呼、核验和收藏使用后台 Win32 UIA；截图通过浏览器插件的一次请求采集多页，再在本地拼接、OCR、评分和生成报表。

- 隔离全新安装完成，未建立信任时项目保持锁定；隔离桌面成功创建配置、记录目录及 HR 模板。
