# 自动执行流程（1.4.16-beta）

当前规则见 [执行契约](current-execution-contract.md)，页面操作与 needs_browser 见 [浏览器交接契约](browser-plugin.md)。

1. 按 quick_start.py 和实时桌面岗位文档选岗，保留用户人数；明确唯一岗位直接准备启动，不重复要求人工筛选确认。
2. 后台 UIA 复用当前聊天BOSS页面，并保存浏览器插件实际标签页绑定供截图，创建/续接原运行与唯一执行器。
3. workflow_runner 使用 HybridAdapter；页面读取、点击、滚动、同事、招呼和收藏直接后台执行。只有截图由 workflow_handoff 返回 needs_browser，模型一次生成完整截图并回填。其他AI交接按已读材料回答，提醒实际展示后才回填 displayed:true。
4. 列表初筛→打开同人简历→平台招呼状态→同事→完整截图/OCR→规则和必要AI复盘→预留共享名额→插件点击一次及平台核验→收藏→等待及收尾。具体阈值沿用岗位快照。
5. 暂停/继续/停止保留检查点；过期或已认领请求不重放，发送回执丢失先只读verify。截图及点击等不再使用旧UIA或桌面前置脚本。
6. 报表失败留待补；达到本轮数量目标并完成所需收尾后停止，同岗同日更新唯一日报，按用户选择才打开表格。
