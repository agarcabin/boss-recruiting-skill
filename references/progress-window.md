# 投递进度悬浮窗

外观与原顶部双区圆角半透明条一致。python.exe scripts/launch_progress.py --run <id> --output-root <桌面根>，无控制台；统计查看人数覆盖列表卡片和简历，预计查看基线300人。

暂停保留原行为，不延长4小时自然截止。结束按钮无二次确认，调用独立stop_controller；关闭窗口也走同一收尾。数量触顶显示完成当前候选人，不允许进入下一人。每秒检查截止、手动状态及数量完成；手动或超时优先于数量收尾。

统一停止契约见 [evaluation-modes.md](evaluation-modes.md)：与派发共用互斥锁、代次隔离迟到写入、本聊天中断、登记helper最多5秒收尾、快照报表、关闭悬浮窗后打开Excel。终止worker在独立线程运行，不依赖被停止的agent；操作失败不谎报成功。

修改后验证无控制台、两区顶部对齐、文字不重叠、状态区穿透、按钮命中及停止收尾。无真实招呼演示验证时间/数量/手动三种终止及只中断绑定回合。

悬浮窗用launch_progress.py启动，独立于会被取消的agent工具进程job；无法独立启动则不进行候选人操作。控制器自身不登记为可取消的OCR/helper。
