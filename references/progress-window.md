# 投递进度悬浮窗

1.5.6-beta：悬浮窗不抢焦点要求覆盖整个独立进程启动过程，不能只在显示完成后核对前台窗口。Windows 使用 `overlay_native.NativeRoot`，以 NOACTIVATE/TOOLWINDOW/LAYERED 属性创建原生窗口、SW_SHOWNOACTIVATE 显示、WM_MOUSEACTIVATE 返回 MA_NOACTIVATE，绘制、计时和按钮回调都不创建 Tk 顶层窗口；保留既有进度与控制逻辑。后台进程通过隐藏隐式启动窗口的 STARTUPINFO 启动，不以事后恢复用户焦点替代防止失焦。测试应捕捉启动全程的前台、输入焦点和光标变化，并验证按钮回调及计时器。环境测试只读检查 Codex 可见性，不再最大化。用户主动操作所需的确认/错误对话框通过独立对话框入口显示。

`python.exe scripts/launch_progress.py --run <id> --output-root <目录>`，创建运行后仍须确认悬浮窗可见。

1.5.5-beta：按钮栏为“暂停 / 结束 / 查看报告 / 切屏目标”。Codex 在主屏时，最后一钮显示黄色“副屏”；在副屏时显示绿色“主屏”，每秒随窗口实际位置刷新，手动拖动也会更新。点击只将本轮已绑定的 Codex/BOSS 窗口从主屏移至副屏或从任意副屏移回主屏，并铺满目标屏工作区；多个副屏时优先复用本轮上次使用的副屏。绑定文件由 workflow_runner 保存并在每次移动前重新核验进程、聊天及BOSS文档；窗口重建或聊天变化时提示重新绑定，不猜测其他窗口。无真实副屏时按需启动虚拟副屏，不影响运行状态。状态栏和按钮栏持续置顶且固定在主屏，两部分都不自动激活。按钮只在单显示器时按需安装/启停虚拟显示驱动，有真实副屏时不创建虚拟屏。切屏与单次截图共用动作锁；切屏导致长图区域变化时中断本次采集，露出窗口后回复继续。

控制口径见 [control-policy.md](control-policy.md)。无自然截止和滚动额度，按本次target/max_views判断数量完成；查看预计基线使用当前max_views。

1.1.2：指示灯直径52像素，信息从82像素起排，状态区扩为710像素，按钮整体右移。字体与布局按缩放调整。已招呼后显示平均速度，分母为本轮candidate_progress查看数，分子为本轮扣除暂停的有效运行秒数；仅查看数变化时更新并保存在overlay_metrics，重开窗口不重采样，零人显示--。今日人数仍取实际工作簿，不与本轮均速混算。阶段显示操作、真实候选人姓名和有效阶段秒数；phase_started_elapsed随阶段切换保存，暂停不累计，旧单步数据姓名缺失时如实显示姓名未知。

启动自动按招聘标题绑定准确聊天。标题不同于默认时传`--chat-title "准确标题"`，自定义标题即使首次绑定失败也会保存供后续重试。暂停先暂停招聘，再在独立线程中调用对应聊天的停止按钮，等待按钮消失确认；已处于空闲态记idle。按钮改为“请在 Codex中回复‘继续’”并禁用点击恢复。收到继续后对原run执行`python scripts/ledger.py control --run <id> --action resume`，续接原执行器；执行器已退出时从原检查点重新启动，不重建运行。

结束先写停止状态，独立控制器中断Codex并收尾导出。绑定失效时按准确标题重新定位，保留进程、Document和聊天工具栏核验；不依赖重绘后失效的scope RuntimeId。切到其他聊天/无法定位对应聊天时明确提示中断失败，不能误停当前其他聊天，不能声称后台思考已停止。UIA尚不能可靠中断隐藏聊天。此限制不阻止招聘暂停/结束。所有这些后台控制、采集、OCR和UIA子进程设置CREATE_NO_WINDOW及隐藏启动参数，保留stdout/stderr用于诊断。

结束由独立控制器处理：写停止状态、取消本轮登记helper、生成结束快照、关闭悬浮窗并显示Excel。报表或归档欠缺不阻止停止，也不伪造成功或完整证据。状态/按钮文字和计数失败应如实报告。
