# 页面自动化（1.4.16-beta）

BOSS 页面默认使用包内定向 Win32 UIA，在后台读取和操作。只有原本需要前台的截图使用 [浏览器](plugin://browser@openai-bundled)，具体见 [浏览器交接契约](browser-plugin.md)。

- UIA 查询使用定向控件范围和实际页面状态。优先 Invoke、Selection、Scroll 等后台控件模式；不得为了普通点击自动前置窗口或使用全局鼠标键盘。
- 只有截图通过 Browser；一个 capture 请求可连续滚动正文并返回多页 JPEG。不得调用旧 Win32 屏幕截图，也不得用桌面坐标替代插件截图。
- 默认 HybridAdapter 只对 capture 发出 needs_browser。UIA 页面动作不产生浏览器交接，后台保留评分、限速、账本、OCR 和报表。
- 招呼须已经过岗位及同事检查并预留共享名额，点击后以平台按钮变化核实；已认领截图操作不盲目重试，发送回执丢失先 verify。
- 页签、候选人及简历文档必须始终对应本次请求；验证码、退出或发送限制按当前执行契约暂停处理。

仓库中旧 UIA/Win32 页面脚本是本版本后台执行路径；旧鼠标轨迹、SendInput、窗口前置和桌面截图不作为运行入口。
